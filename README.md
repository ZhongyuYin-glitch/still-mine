# Still Mine?

An interactive fiction about AI assistance and personal agency. Created for an art and media final project.

Play as Tom’s AI through messages, memory and reunion plans. All characters and responses are fictional. Images are AI-generated. No live AI API, account, analytics or database is used. Reflection text stays in the current browser session.

## Source

Download and extract `still-mine-source.zip`, then run `npm ci` and `npm run dev` with Node.js 22 or newer. Run `npm test` and `npm run build` to verify.

This repository contains the static production build with assets flattened for GitHub Pages. Pages serves `main` at the repository root.
